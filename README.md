# 🚭 App para Dejar de Fumar

Una aplicación móvil diseñada para acompañarte en el proceso de dejar de fumar. Basada en **React Native** (con **Expo**) y respaldada por **SQLite** para la gestión de datos, esta herramienta combina tecnología y enfoques interdisciplinarios de la Policlínica de Tabaquismo en Uruguay. 

## ✨ Características Principales

- **Registros de cigarrillos:**  
  Permite registrar cada cigarrillo fumado, asociado a un motivo específico.

- **Motivos de consumo:**  
  Registra y clasifica los motivos según las **4 esferas del tabaquismo**:
  - **Social:** Influencia de amigos, eventos o contexto social.
  - **Emocional:** Estrés, ansiedad, tristeza, entre otros.
  - **Conductual:** Hábitos adquiridos, como fumar después del café.
  - **Fisiológico:** Necesidad física de nicotina.

- **Pantalla de resumen configurable:**  
  Una vista dedicada al progreso del usuario, que muestra un resumen (por defecto semanal) del proceso de intentar dejar de fumar.  
  - **Beneficios:** Tanto los pacientes como los profesionales que los atienden pueden compartir información representativa y de alto valor.  
  - **Configuración:** Ajustable para analizar períodos específicos según las necesidades.

- **Gestión de datos:**  
  La información se almacena internamente usando **SQLite**, con la opción de exportarla si el almacenamiento del dispositivo se llena.

## 🚀 Futuras Mejoras

Estas son algunas características que planeamos incorporar en futuras versiones:

1. **Sistema de alertas personalizadas:**  
   Recordatorios para ayudar al usuario a mantenerse enfocado en sus objetivos.
   
2. **Personalización:**  
   Adaptar la experiencia según la usabilidad y preferencias del paciente.

3. **Registro de desencadenantes:**  
   Identificar qué situaciones, emociones o contextos provocan el consumo.

4. **Asociación entre desencadenantes y motivos:**  
   Relacionar los motivos registrados con sus desencadenantes específicos.

5. **Seguimiento de emociones diarias:**  
   Registrar estados emocionales para contrastarlos con la información sobre consumo.

6. **Conexión con API:**  
   Posibilidad de sincronizar los datos con un sistema externo para análisis y respaldo.

## 🛠️ Tecnologías Utilizadas

- **React Native** (con Expo): Desarrollo de la interfaz móvil.
- **SQLite**: Gestión local de datos.
- **Expo-SQLite**: Librería para trabajar con SQLite en React Native.

## 🎯 Objetivo

Esta aplicación no solo busca ayudarte en el proceso de dejar de fumar, sino también ser una herramienta valiosa para equipos interdisciplinarios como el de la Policlínica de Tabaquismo en Uruguay. La información recolectada puede contribuir al análisis y desarrollo de estrategias más efectivas para combatir el tabaquismo.
